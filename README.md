# Germany MSc Tracker — Summer 2027

Live tracker for Raghul S's applications to English-taught AI / Data Science master's programmes in Germany that are open for the Summer Semester 2027 intake.

**Live site:** https://raghuls33.github.io/germany-ms-tracker/

## What's inside
- **Overview** — next deadlines, progress per university, profile facts
- **Timeline** — application windows, deadlines, recommended submit-by dates, visa triggers
- **Universities** — 21 programmes with portal, English rule (MOI or test), fees/tuition, test, odds estimate, what raises the odds, ECTS requirement mapping and official sources; per-programme status and 8-step checklist
- **ECTS mapping** — 166 SIMATS credits → 240 ECTS by subject area, requirement check per programme
- **Courses & marks** — all 42 courses by semester with grades, credits, ECTS and syllabus units
- **Tasks** — shared to-dos (IELTS, MOI letter, LORs, loan, blocked account, visa…)

## Progress
Progress is saved in the browser (localStorage). Use **Export progress** to download `progress.json`; commit it to this repo to make it the default view on every device.

## Privacy
No original documents (mark sheets, certificates, passport, scans) are published. Date of birth, register number and address are not included.

## Updating data
All data lives in `data.js`. Facts were checked on 28 Oct 2026 against official university and DAAD pages linked on each card; odds are estimates, not published admission rates.
